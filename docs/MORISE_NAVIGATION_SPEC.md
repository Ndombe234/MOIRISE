# MORISE — Navigation & Visual UX Specification

## Goal

Make MORISE immediately understandable like a mainstream social product while keeping 100% MORISE visual identity.

## Primary navigation

The primary bar must stay compact and permanently understandable. It must not expose every feature.

Recommended mobile-first structure:

- WORLD
- ALLIES
- LINK
- PLAY
- MENU

The exact iconography can evolve, but labels/icons must remain recognizable without requiring the user to learn the SYSTEM first.

## MENU

Secondary features are grouped into clear sections rather than placed in the primary bar.

### PLAYER
- Profile
- Titles
- Achievements
- Activity

### SOCIAL
- Moments
- Burst
- Vault
- Alerts

### WORLD
- Discover
- Create
- Communities / Guilds
- Activities
- Events

### PLAY
- Games
- Solo
- Collective
- Challenges
- History

### SYSTEM
- Missions
- Rewards
- Progression
- Settings

## UX rules

1. Never expose a wall of buttons.
2. Primary actions are always visible.
3. Secondary actions live in MENU or contextual screens.
4. One visual hierarchy per screen.
5. Comfortable contrast: avoid pure-black + high-neon combinations.
6. Use breathing room and consistent grouping.
7. Buttons must look clickable without relying on hover.
8. Mobile touch targets should be comfortable.
9. Preserve the same information architecture on desktop, adapting the geometry rather than duplicating navigation.
10. Do not copy Facebook/Instagram colors, branding or visual assets. Only use their familiar information-architecture principle as UX inspiration.

## MORISE visual direction

- dark-but-soft surfaces rather than pure black;
- calm blue/cyan foundation;
- restrained violet/gold accents;
- readable text hierarchy;
- subtle SYSTEM details instead of constant neon effects;
- cards and dividers used to group information, not decorate everything;
- content remains the visual priority;
- motion is purposeful and reduced when appropriate.

## Validation

A first-time user should be able to locate World, Allies, Link, Play and Menu without instruction, then discover secondary features from Menu without feeling overwhelmed.
