# M15 — META SYSTEM

## Goal
Expose advanced System coordination, creator workflows, experiments and controlled AI-assisted evolution without exposing internal complexity as permanent navigation.

## UI
SYSTEM panel, contextual alerts, creator lab and diagnostics where authorized. The ordinary player sees a clean surface.

## MORISE
Coordinates skills, memory, provider routing, creative tasks, game creation and validated improvement proposals.

## Safety
No unrestricted self-modification. Evolution uses sandbox, tests, benchmark, policy, canary and rollback contracts defined in AI architecture.

## Acceptance
Advanced features are permission-gated, auditable, reversible and isolated from the ordinary player experience.
