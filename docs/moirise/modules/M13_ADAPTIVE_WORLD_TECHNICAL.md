# M13 — ADAPTIVE WORLD

## Goal
Use validated aggregate signals to adapt discovery, activities and world presentation.

## Signals
Public/eligible engagement, completion, feedback, trends and event outcomes.

## MORISE
Generates adaptation candidates; deterministic policy and evaluation decide whether an adaptation activates.

## Anti-poisoning
No single user or single provider can directly rewrite global world behavior.

## Acceptance
Adaptations are explainable, versioned, measurable and reversible.
