# M05 — SYSTEM / PROGRESSION — CONCEPTION TECHNIQUE

## SYSTEM context
M15 fournit ContextSnapshot; M05 convertit ce contexte en actions, statut et progression visibles. Les surfaces ont des priorités et règles de suppression.

## Progression
XP = transactions autoritaires. Level/rank = projections déterministes. Title unlock = evidence + grammar/version. Achievement = evidence ref.

## Return prompts
Un rappel futur n'est valide que si un module propriétaire a persisté un vrai état futur. M05 ne fabrique jamais un événement.

## First session
0–120s = fenêtres comportementales, pas compte à rebours : orientation → première valeur → révélation → prochaine action/continuation. Les interventions non critiques sont supprimées pendant une activité intense.

## Security
Le client ne fixe jamais XP, rank, title ou reward. M15 propose; M05 et les propriétaires valident/commit.

## Tests
Idempotence progression, preuve de titre, duplicate reward, suppression contextuelle, test vrai/faux état futur, mobile System drawer, absence de spam.
