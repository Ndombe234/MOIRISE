# M05 — SYSTEM / PROGRESSION — PLAN CANONIQUE

## Mission
Créer l'interface SYSTEM principale et posséder l'affichage/progression : contexte, commandes, XP, niveaux, rangs, titres, achievements, missions, récompenses et continuités réelles.

## Fonctionnalités détaillées
1. SYSTEM HUD et surfaces contextuelles.
2. Contextual actions : une action utile à la fois lorsque possible.
3. SYSTEM messages naturels : guidance, découverte, succès, avertissement, erreur.
4. XP et niveaux avec journal serveur-authoritative.
5. Rangs et jalons.
6. Titres : déblocages déterministes; grands espaces de titres sans précréer des millions de lignes.
7. Achievements et preuves d'unlock.
8. Missions : présentation et suivi; M12 propriétaire des événements réels, M15 des mécanismes émergents.
9. Reward presentation sans autorité artificielle.
10. Return prompts uniquement lorsqu'un état futur existe réellement.
11. First-session progressive reveal : orientation → première valeur → découverte → prochaine action.
12. Suppression contextuelle : ne pas interrompre inutilement pendant écriture/jeu/création/lecture.
13. SYSTEM progression language inspiré du concept de personal progression UI, mais visuellement/originalement propre à MOIRISE.

## IA
M15 propose/orchestre. M05 refuse les fausses urgences, faux événements et faux compteurs. L'IA ne modifie jamais directement XP/récompenses/titres.

## DONE
SYSTEM utile sans spam, 5–6 portes principales maximum, progression persistante, missions lisibles, return state réel, mobile/desktop, tests de reprise et de permissions.
