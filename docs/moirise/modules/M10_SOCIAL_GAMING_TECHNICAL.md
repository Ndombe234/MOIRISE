# M10 — SOCIAL GAMING

## Goal
Connect gameplay with social interaction without turning Play into a second social network.

## Features
Challenges, shareable results, co-play invitations, leaderboards and game-related posts.

## MORISE
Can propose challenges or explain results using validated game events. It cannot fabricate scores.

## Privacy
Private game sessions remain private. Public leaderboards require explicit eligibility.

## Acceptance
Challenge creation, participation, result validation, sharing and abuse controls work across mobile/desktop.
