# MORISE AI — PLAN MAÎTRE CANONIQUE

## Mission
MORISE AI est un système natif codé dans MOIRISE. Les modèles/API externes sont des composants auxiliaires, jamais le cerveau.

## Loop
OBSERVE → CONTEXTUALIZE → UNDERSTAND → POLICY → PLAN → RESERVE RESOURCES → EXECUTE → VALIDATE → CORRECT/ASK → COMMIT → EVENT → SAFE EXPERIENCE.

## Native mechanisms
Context Engine; Intent/Requirements; Reasoning; Planner/Task Graph; Capability Registry; Action Registry; Memory; Experience Learning; Provider Router; Resource Scheduler; Specialist Agents; Validation; Self-Correction; Evaluation; Evolution Engine; AI Lab.

## Specialist mechanics
Social Agent; Community Agent; Game Discovery Agent; Game Design Agent; Creator Agent; Safety Agent; Economy Agent; Personalization Agent; SYSTEM Orchestrator.

## Signature MORISE mechanics
Living Objects; Evolution Engine/Fun & Surprise; MORISE DNA; Convergence; Missions From Reality; World Memory.

## Creation
Image/video/audio/music/text/voice/vision; game 2D/3D; GameSpecification; controlled engines; simulation; tests; preview; publication.

## Evolution
Limitation → capability gap → hypothesis → design → code/algorithm candidate → sandbox → static/type/security checks → behavioral tests → benchmark → policy gate → canary → promote/reject → rollback → experience.

## Local/distributed
Local/on-device/browser execution first where suitable; Trusted Workers; Community Workers opt-in; scheduler with hard constraints and leases. Community Worker default is 1 logical CPU + 512 MiB RAM, GPU off.

## Privacy
Context and memory are scoped. Private messages are not global learning material. Sensitive attributes are not inferred for recommendation. Provider destination policy is enforced before execution.

## Authority
M01 auth/security; M03 private/social data; M11 communities; M12 future-event truth; M13 world change; M14 reward economy. M15 orchestrates but does not become superuser.

## Definition
MORISE AI is not complete because a provider can answer a prompt. The native mechanism, state, policy, validator, tests and integration must exist.
