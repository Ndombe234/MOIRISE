# MORISE PLAY — Market Intelligence

Updated: 2026-09-28

## Signals used for the current Play Lab expansion

- **Low friction matters.** The 2026 State of Web Gaming report says 46% of surveyed web gamers stopped playing a mobile game because it took too long to open/load, and 92% described HTML5 web games as quite or very high quality. This supports short, instant-start experiences rather than heavyweight first sessions.
- **Social play is a core web behavior.** The same report says 54% of surveyed consumers play web games with a friend or family member often or very often. MORISE therefore treats every run as a future social object: score, moment, challenge, and replay hook.
- **Short loops are useful for discovery.** Current 2026 browser-game trend reporting highlights one-button skill games, daily puzzles, and short satisfying loops as clip-friendly formats. MORISE avoids copying those games directly and instead borrows the distribution property: a result should be understandable from a short clip.
- **Puzzle remains commercially relevant, but cloning is crowded.** 2026 market reporting points to strong puzzle performance and rapid growth in sort/physics/puzzle subgenres. MORISE uses puzzle structures only when combined with a distinct interaction or system layer.
- **Small, focused games are strategically useful.** Unity's 2026 developer report describes a shift toward shorter, tightly scoped games and identifies online multiplayer, cross-play, daily rewards/missions and leaderboards as common engagement investments. MORISE can use the same modular approach without requiring every game to be multiplayer on day one.

## Current original game directions

1. **Echo Trace** — memory + reconstruction.
2. **Signal Bloom** — timing + visual calibration.
3. **Shadow Courier** — route construction + experimentation.
4. **Mirror Run** — rotating network puzzle + discovery moment.
5. **Last Second** — reactive survival + clip-friendly near-miss moments.

## Design rule

The system may create additional games whenever market signals justify a new mechanic. The goal is not to reach a fixed count of games; it is to build a rotating library where each experience has a distinct core interaction, a short readable loop, a progression signal for SYSTEM, and a natural reason to share the result.
