# MOIRISE

MORISE — world social platform with an evolving personal SYSTEM.

## Project status

Module 0 — Foundations

This repository is intentionally starting from zero.

## Product principles

- Simple surface, deep architecture.
- Every user is a Player.
- The SYSTEM is a dedicated destination.
- Solo-first: users can discover, play, explore, create and progress alone.
- Social depth emerges from real user actions.
- No fake users, fake engagement or fake statistics.
- Global and multilingual by design.
- Railway for validation/build.
- Cloudflare for final production.
- Vercel is not used unless explicitly justified.
